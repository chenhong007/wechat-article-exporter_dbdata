## ⚠️ 注意事项

### 1. 浏览器兼容性
- ✅ Chrome 90+
- ✅ Firefox 88+
- ✅ Edge 90+
- ⚠️ Safari 需要测试（可能有兼容性问题）

### 2. 性能考虑
- 大数据量（> 10000 条）导入可能需要 10-30 秒
- asset 表的 Blob 数据会显著增加导出文件大小
- 建议定期清理不需要的资源

### 3. 数据安全
- 所有操作在本地浏览器进行
- 不涉及服务器传输
- 导入是追加式，不会自动覆盖
- 建议定期导出备份

### 4. 已知限制
- Windows 构建可能有路径错误（Nuxt 问题）
- 建议使用 `npm run dev` 开发模式
- 生产构建需要额外测试
